## Decisions & learnings (append as you go)

- 2026-06: Cloudflare proxied (orange) + SSL "Full" chosen over Netlify Let's Encrypt (rate-limited during DNS move).
- 2026-09: Paddle over Stripe (Saudi residency). Phase 1 needs no payments.
- 2026-09: Dixon-Coles rho regularised toward -0.06 with bounds [-0.2, 0.1]; with < 10 matches an
  unregularised fit drove rho to its bound and forced every prediction to 1-1.
- 2026-09-12 (Phase 0): Phase 0 was first built in `D:\Projects\fantasy-predictor` on the belief it
  was the deployed repo. It is not — fplanalytic.com deploys from THIS repo (`fpl-analytics`,
  GitHub `maballouk/fplanalytic` → Netlify on push to main). Work migrated here on branch
  `phase-0-foundations`; the prototype repo stays as an archive. "Twice Daily" turned out to be the
  12h ISR cache (`revalidate: 43200`) on `/api/fpl`, not a build hook.
- 2026-09-12: DESIGN.md tokens now own the shared Tailwind keys (`text-base`, `shadow-card`, …), so
  the legacy light screens shift slightly until Phase 1 replaces them. Deliberate; see
  ARCHITECTURE.md §6. Legacy `/api/fpl*` routes stay until 1.10.
- 2026-09-12: FPL `defensive_contribution` (bootstrap, element-summary history, live) is the
  position-aware composite COUNT per match (DEF: CBIT+tackles; MID/FWD: +recoveries), not the points
  awarded. Verified on Gabriel/White/Kamara GW1-3; example rows frozen in `tests/fpl-schemas.test.ts`.
